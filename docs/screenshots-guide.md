---

## 🛠 איך לצלם מסך ב-Windows

**הכי פשוט:** מקש Windows + Shift + S
- בוחרים אזור עם העכבר
- הצילום נשמר ב-clipboard
- אפשר להדביק (Ctrl+V) לכל אפליקציה

**או:** Print Screen (PrtScn)
- מצלם את כל המסך
- נשמר ב-clipboard

**או:** Snipping Tool (חיפוש Windows → "snipping")
- ממשק נוח לבחירה והערכה

## ✨ טיפים לצילומים מקצועיים

### 1. רקע נקי
- סגור טאבים מיותרים בדפדפן
- הקטן את הטולברים
- F11 למצב מלא מסך

### 2. מצב כהה / בהיר
- Streamlit ברירת מחדל מתאים את עצמו למערכת
- מצב **בהיר** נראה מקצועי יותר לפורטפוליו
- אפשר לכפות בהגדרות Streamlit (☰ בפינה ימין עליון → Settings → Theme: Light)

### 3. צל וגבול (אופציונלי)
- אחרי הצילום, השתמש בכלי כמו [shots.so](https://shots.so) או Photoshop להוסיף:
  - מסגרת דפדפן
  - צל
  - רקע צבעוני

### 4. הצנע פרטים אישיים
- אם נראה ה-API key איפשהו - צבע עליו
- אם הצ'אט מכיל פרטים פרטיים - מחק או טשטש

**מבנה וידאו של 60 שניות:**
1. **0-10 שניות:** "שלום, אני אורי. בניתי סוכן AI שמנתח חוזים בעברית."
2. **10-25 שניות:** הדגמה - העלאת חוזה, לחיצה על ניתוח
3. **25-50 שניות:** הצגת תוצאות - הצבע על דברים מרשימים (ציטוט חוק, חישוב כסף, ניסוחים חלופיים)

**איך להעלות:**
- Loom: מקבל קישור מיידי לשיתוף
- YouTube (לא רשום ברבים = "Unlisted")
- Google Drive
